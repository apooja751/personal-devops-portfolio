# Personal DevOps Portfolio

## About
This repository demonstrates my learning and practical implementation of DevOps fundamentals using Git, GitHub, and GitHub Actions.

## Objectives
- Understand Git version control and GitHub repositories.
- Maintain project documentation using Markdown.
- Use `.gitignore` to exclude unnecessary files.
- Automate basic checks using GitHub Actions CI.

## Tools and Technologies
- Git
- GitHub
- GitHub Actions
- Markdown
- YAML

## Continuous Integration
A GitHub Actions workflow runs automatically whenever code is pushed to the repository or a pull request is created. It validates the repository structure and checks that essential project files exist.

## Repository Structure
```text
personal-devops-portfolio/
├── .github/
│   └── workflows/
│       └── ci.yml
├── .gitignore
└── README.md
```

## Learning Outcome
This project helps me understand repository management, documentation, file exclusion rules, and basic CI automation.
